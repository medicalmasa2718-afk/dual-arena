# ⚡ DUAL ARENA (デュアル・アリーナ)

> 1台の端末で2人が熱狂できる、ネオンサイバー調の2人対戦Webゲームコレクション！

PCキーボードでの並んでプレイにも、スマートフォン・タブレットを机に置いて向かい合っての画面分割タッチ対戦にも完全対応しています。

---

## 🎮 収録ゲーム

### 1. ⚡ ネオン・エアホッケー (Neon Air Hockey)
- **ルール**: 超高速パックを相手のゴールに叩き込め！5点先取制。
- **アイテム**: スピードアップ（⚡）、巨大パドル（🛡️）、マルチボール（⚽）が出現！
- **操作**:
  - **PC**: P1 `[W/A/S/D]` または マウスドラッグ / P2 `[↑/↓/←/→]`
  - **スマホ**: 画面の自陣側を指でドラッグ（画面の向きに合わせて縦型・横型コートに自動適応）

### 2. 💥 サイバー・タンク (Cyber Tank Arena)
- **ルール**: 迷路のようなアリーナで戦車バトル！3機撃破制。
- **特徴**: 壁で2回跳ね返る跳弾（トリックショット）が可能！
- **操作**:
  - **PC**: P1 `[W/S]` 移動・`[A/D]` 旋回・`[F/Space]` 砲撃 / P2 `[↑/↓]` 移動・`[←/→]` 旋回・`[Enter/L]` 砲撃
  - **スマホ**: 画面端のバーチャルスティックで移動、FIREボタンで砲撃

### 3. 🎯 早押しリフレックス (Reflex Duel)
- **ルール**: 「HIT!!」の合図が出た瞬間に素早く画面をタップ！3本先取制。
- **特徴**: フライングはお手つきペナルティ。ミリ秒（ms）単位の反応時間をリアルタイム計測！
- **操作**:
  - **PC**: P1 `[W/Space]` / P2 `[↑/Enter]`
  - **スマホ**: 自分の陣地をタップ（P2側は対面用に180度回転表示）

---

## 🌟 特徴
- **外部依存ゼロ**: 純粋な HTML5 + CSS + JavaScript (Canvas) のみで動作。
- **Web Audio API**: 音声ファイル不要。ブラウザ内でシンセサウンド・効果音（打撃、跳弾、爆発、歓声、ブザー）をリアルタイム合成。
- **レスポンシブ & 全画面**: モバイルでもデスクトップでも快適に遊べます。

---

## 🚀 遊び方
ブラウザで `index.html` を開くだけですぐにプレイできます。
